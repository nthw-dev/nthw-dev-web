Smart Hire AI สัมภาษณ์งานออนไลน์ ให้ AI ช่วยคัดกรอง

ระบบสัมภาษณ์ผู้สมัครงานแบบอัตโนมัติของ Metanet Corporation ผู้ดูแลสร้าง “ลิงก์สัมภาษณ์” ที่มีคำถามได้ 8 ประเภท ทั้งข้อความ ตัวเลือก อัปโหลด Resume อัดวิดีโอแนะนำตัว และแบบทดสอบบุคลิกภาพ DISC ผู้สมัครเปิดลิงก์แล้วตอบทีละข้อภายในเวลาที่กำหนด โดยไม่ต้องสมัครสมาชิก จากนั้น OpenAI จะให้คะแนนแต่ละคำตอบตามเกณฑ์ที่ผู้ดูแลตั้งไว้ ถอดเสียงวิดีโอ และวิเคราะห์การแต่งกาย ทั้งหมดอยู่ในเว็บ Next.js ฟูลสแตกโปรเจกต์เดียว ที่ใช้ tRPC + Prisma + PostgreSQL

Integration · OpenAI

AI Scoring และการวิเคราะห์ผู้สมัคร

ฟังก์ชัน AI ทั้งหมดอยู่ใน src/server/chatGPTService.ts ใช้ prompt ภาษาไทย และขอผลเป็น JSON (ยกเว้นการถอดเสียง) หัวใจของระบบคือ การให้คะแนนตามรูบริก ผู้ดูแลกำหนดว่าแต่ละเกณฑ์ เช่น “นิสัย” หรือ “ประสบการณ์” ได้คะแนนเท่าไรเมื่อคำตอบเป็นแบบไหน แล้ว GPT จะให้คะแนนพร้อมเหตุผลเป็นภาษาไทยที่ผู้ดูแลอ่านทวนได้

📐การให้คะแนนตามเกณฑ์

  • system prompt ให้ GPT รับบทผู้สรรหาที่มีประสบการณ์ และแนบรูบริกของทุกเกณฑ์ในรูป “ให้คะแนน X หาก …”
  • ขอผลเป็น {data:[{criteriaId, criteriaName, aiResult:{score, note}}]}
  • ทำงานแบบ fire-and-forget หลัง questionAnswer.create ผู้สมัครจึงไปข้อถัดไปได้ทันที
  • ผลบันทึกลง ScoringCriteriaAiResult และจำนวน token ลง ChatGptHistory

  • dressAnalyze จับภาพหนึ่งเฟรมจากวิดีโอด้วย canvas แล้วส่งให้ gpt-4o-mini vision ประเมินการแต่งกาย
  • คำถอดเสียงถูกบันทึกเป็นคำตอบ จึงให้คะแนนตามเกณฑ์ได้เหมือนคำตอบที่พิมพ์

🧠DISC และการสร้างคำถาม

  • generateQuestionByGpt (gpt-4o-mini) สร้างคำถามสัมภาษณ์ภาษาไทยหนึ่งข้อพร้อมรูบริก ไม่ซ้ำคำถามเดิม และใช้หลัก DISC กับคำถามด้านบุคลิกภาพ
  • Resume ถูกแปลงเป็นข้อความในเบราว์เซอร์ก่อน แล้วให้คะแนนผ่านเกณฑ์ชุดเดียวกัน
